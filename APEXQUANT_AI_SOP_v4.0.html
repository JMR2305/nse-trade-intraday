1. Executive Summary

1.1 What is ApexQuant AI?

ApexQuant AI is a paper-only NSE trading research platform built on a multi-agent AI architecture. Its core purpose is to:

  • Scan NIFTY 50 (51 symbols after TATAMOTORS demerger) every 5 minutes during market hours
  • Run each symbol through a multi-layer AI pipeline: data quality → signal → strategy → risk → decision → execution
  • Generate BUY / WATCH / IGNORE recommendations with confidence scores, opportunity scores, and position-sizing guidance
  • Execute paper (simulated) trades when all gates pass, building a tracked portfolio
  • Learn from the outcomes of those paper trades to improve future decisions

No live orders have ever been placed, and no Zerodha broker APIs are called for order submission. Live execution is structurally disabled.

3.1 Main Scan and Execution Pipeline


START SCAN TICK (every 5 minutes, 09:15–15:30 IST)
│

│
├── [STEP 2] Data Fetch: LiveDataProvider.fetch_batch(universe)
│   │   Provider: Yahoo Finance (yfinance) — the ONLY OHLCV source
│   │   Interval: 1d (daily bars), Period: 6mo
│   │   Kite: NOT involved in this step.
│   └── Output: {symbol: SymbolFetchResult} — OHLCV + age_days + quality per symbol

│   │   [DATA QUALITY GATE] _apply_quality_gate()
│   │   [R:R GATE] rr_ratio < 1.5 → downgrade to WATCH
│   │   [MARKET CONTEXT] Apply regime modifier
│   │   [OPPORTUNITY SCORE] trade_quality×0.40 + confidence×0.30 + rr×0.20 + market×0.10
│   │   [STRATEGY] Select MOMENTUM / BREAKOUT / MEAN_REVERSION

│

│   │   kite_ltp_overlay.fetch_ltp_overlay(all_symbols) — ONE bulk Kite call
│   │   For each rec:
│   │     build_symbol_overlay(symbol, yfinance_close, yfinance_dq, ltp_result)
│   │     apply_overlay_to_rec(rec, overlay)
│   │   Option A invariants enforced:
│   │     indicator_source    = "yfinance_daily_bars"  ← NEVER changes
│   │     ohlcv_source        = "yfinance_daily_bars"  ← NEVER changes
│   │     data_quality_for_indicators = yfinance DQ    ← NEVER changes
│   │     yfinance_last_close = entry_price at scan    ← always preserved
│   │   When Kite LTP available:
│   │     kite_ltp                  = live LTP
│   │     kite_ltp_available        = True
│   │     current_price_source      = "kite_live_ltp"
│   │     execution_price_source    = "kite_live_ltp"
│   │     quote_reliable            = True
│   │     data_quality_for_execution = "LIVE"
│   │   When Kite unavailable: all fields stay yfinance defaults (silent fallback)
│   └── timings["ltp_overlay_s"] recorded; safety dict updated

├── [STEP 4] Paper Execution: phase20_gates.evaluate_entries()
│   │   For each BUY candidate:
│   │     signal_price = kite_ltp (when available) OR yfinance close [UPDATED v4.0]
│   │     evidence records both signal_price_from_daily_bar AND execution_price_from_kite_ltp
