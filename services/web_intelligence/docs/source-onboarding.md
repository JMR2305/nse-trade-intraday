# Source Onboarding Checklist

Before adding any new source, the following must be completed:

1. **Source Owner**: Named individual responsible
2. **Business Purpose**: Why this source is needed
3. **Public Access Confirmation**: Confirmed publicly accessible, no login required
4. **Terms Review**: Website terms of service reviewed
5. **Robots Review**: robots.txt reviewed and respected
6. **Permitted Rate**: Agreed request frequency
7. **Data Fields Required**: Exactly what fields will be extracted
8. **Parser Owner**: Named individual responsible for parser maintenance
9. **Retention Policy**: How long data is retained
10. **Legal/Compliance Approval**: Signed off by compliance
11. **Test Fixture**: Local HTML fixture for deterministic testing
12. **Fallback Behaviour**: What happens when parser fails
13. **Disable Switch**: Source can be disabled immediately
14. **Monitoring Owner**: Who receives alerts

**Do NOT scrape NSE or live price feeds without explicit legal and compliance review.**
