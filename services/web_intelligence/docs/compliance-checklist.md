# Compliance Checklist

## What the Collector Does
- [x] Collects only publicly accessible information
- [x] Uses only explicitly approved sources
- [x] Respects website terms and robots guidance
- [x] Identifies itself via configurable user agent
- [x] Uses conservative request frequency
- [x] Supports per-domain request limits
- [x] Retains source URLs and retrieval timestamps
- [x] Preserves raw evidence for audit
- [x] Stops collecting when source is disabled
- [x] Fails safely when parsing becomes unreliable

## What the Collector Never Does
- [x] Does NOT bypass logins
- [x] Does NOT bypass paywalls
- [x] Does NOT solve or bypass CAPTCHAs
- [x] Does NOT evade access controls
- [x] Does NOT use stolen cookies or credentials
- [x] Does NOT impersonate a browser user
- [x] Does NOT scrape personal or private information
- [x] Does NOT collect live prices for trading
- [x] Does NOT send broker orders
- [x] Does NOT call Zerodha
- [x] Does NOT modify ApexQuant trade or portfolio records
- [x] Does NOT access the core trading database
- [x] Does NOT make trade recommendations
- [x] Does NOT label extracted information as verified without validation
