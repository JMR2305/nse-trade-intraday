## 1. Same-pipeline guarantee (the core requirement)

The backtest does **not** contain a second decision engine. Proof by imports:

- `backtest_runner.py` imports and calls **`live_scan_engine._scan_one(...)`** —
  the identical per-symbol production pipeline function used by every live scan
  (scanner → research → market intelligence → monitoring → strategy → risk →
  AI decision). The backtest only changes the *data* handed to it: an as-of
  candle slice instead of a live fetch.
- Event derivation was refactored into **`live_scan_engine.derive_symbol_events(recs, scan_id, mode, run_id)`**
  and is now the single code path used by BOTH `run_live_scan` (mode=LIVE) and
  `backtest_runner.execute_run` (mode=BACKTEST). Identical event shapes by
  construction.
- Fills and charges reuse **`phase20_executor.compute_fill` / `compute_charges`**
  with the same DEFAULT_SETTINGS (NEXT_QUOTE, 0.15% slippage, 0.12% charges).

## 3. Replay validation (replay ≡ pipeline)

`GET /api/backtest/run/BT-85a4febee3/validate?sample=15`:
```
checked: 15, mismatches: [], verdict: MATCH
```
Validation re-runs `_scan_one` on the exact as-of candles AND the recorded
per-tick cash the replay used (`cash_by_tick`, persisted on the run). It
compares action and confidence; skipped decisions are counted, and the
verdict is honest: `INDETERMINATE` when nothing could be checked or when the
adaptive-learning fingerprint changed since the run (a diff would then be
environmental, not a pipeline bug); `MISMATCH` only for genuine divergence.
Covered by `test_validation_replay_equals_pipeline`.

### Run-once guarantee

`backtest_exec` atomically claims the run (conditional PENDING→RUNNING
update). A duplicate or retried exec refuses to run — a backtest can never
replay twice or corrupt its trades/metrics (covered by
`test_run_cannot_execute_twice`).

## 4. No look-ahead

`build_asof_df(daily, intraday, ts, interval)` includes only bars ≤ ts (daily)
or bars < day-start plus a partial "today" bar aggregated from intraday ≤ ts.
Covered by `TestNoLookahead` (future bars excluded; partial-day bar never sees
later candles). No same-bar exits: trades opened at tick T are not exit-checked
at tick T.

## 5. Isolation from live

- Dedicated tables/files: `backtest_runs`, `backtest_trades`,
  `backtest_candles` (+meta, corporate actions). The live phase20 ledger is
  never written; `test_full_run_pipeline_and_isolation` asserts the live
  ledger length is unchanged across a full backtest run.
- All backtest events carry `mode=BACKTEST` + `run_id`; LIVE queries never see
  them (asserted in tests). UI is permanently labeled
  "BACKTEST — SIMULATED, ISOLATED FROM LIVE".

## 6. Candle cache (never re-download)

`historical_data_engine.py` records coverage windows per (symbol, interval);
an identical or contained range triggers **zero** downloads (unit-tested with
a counting stub). 10m candles are resampled from cached 5m. Intraday ranges
older than ~55 days return an explicit error — never silent truncation.
Corporate actions cached ≤ once/day per symbol.
