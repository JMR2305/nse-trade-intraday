Build Sprint 3 - Module 2A: Historical Knowledge Base.

Purpose:
Create a large historical training dataset from Yahoo Finance before building the Learning Engine.

Important:
- Do not change existing strategy logic.
- Do not place real orders.
- Paper/research only.
- Use Yahoo Finance data only.
- If Yahoo data fails, skip that symbol and log it. Do not use mock data for historical knowledge.

1. Create backend module:
backend/historical_knowledge_builder.py

2. Data universe:
Use NIFTY 50 stocks.
Convert symbols to Yahoo format:
SBIN -> SBIN.NS
RELIANCE -> RELIANCE.NS

3. Historical period:
Default: 5 years
Options:
- 1 year
- 3 years
- 5 years

4. Run all existing strategies:
- EMA Cross
- MACD Cross
- RSI Mean Reversion
- Trend Rider
- Breakout
- Supertrend

Do not modify strategy rules.

symbol
sector
strategy

exit_price
quantity
profit_loss
return_percent
winning

market_regime

Decision metrics:
opportunity_score

historical_knowledge_trades

symbol + strategy + entry_date + exit_date
