TASK 2 — DEFINE STRICT JOB TYPES

Every scheduler event / scan event must have a clear job type:

1. MARKET_SCAN
   - allowed only during NSE market hours
   - suggested window: 09:15–15:20/15:30 IST
   - runs scan, indicators, AI decision, risk, bootstrap, paper-entry eligibility, exit checks

2. POSTMARKET_CACHE_REFRESH
   - runs once after market close
   - updates local OHLCV cache only
   - no AI decision
   - no paper entry
   - no BOOTSTRAP_AUTO

3. PREMARKET_READINESS_CHECK
   - runs once around 08:45–09:05 IST
   - checks cache, Kite, capital, universe, circuit breaker, open positions
   - no AI decision
   - no paper entry
   - no BOOTSTRAP_AUTO

4. SYSTEM_HEARTBEAT
   - lightweight health check only
   - no full scan
   - no yfinance bulk fetch
   - no AI decision
   - no paper entry

5. MANUAL_SCAN
   - only if explicitly operator-triggered
   - must clearly show triggered_by=manual
   - must still block execution if market_state != OPEN

Every SCAN_STARTED / SCAN_COMPLETED or equivalent event must include:

TASK 4 — POST-MARKET CACHE REFRESH POLICY

OHLCV cache refresh should run once per IST day:

- after 15:30 IST
- guarded by kv_claim_once("ohlcv_postmarket_refresh:{YYYY-MM-DD}")
- fetch latest daily candle / last 5 days only
- append/update local cache
- emit DATA_CACHE_POSTMARKET_REFRESH_COMPLETED or DATA_CACHE_POSTMARKET_REFRESH_FAILED
- should not run again until next trading day unless manually forced by operator

If yfinance fails:
- preserve existing local cache
- mark refresh PARTIAL or FAILED
- do not run repeated full scans every few minutes
- retry later with controlled backoff, not full live scan loop
