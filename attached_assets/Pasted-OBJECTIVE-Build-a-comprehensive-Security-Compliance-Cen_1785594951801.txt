OBJECTIVE

Build a comprehensive Security & Compliance Centre for ApexQuant AI.

This module continuously audits platform security, configuration, authentication, secrets, APIs and compliance posture.

This module MUST remain completely READ-ONLY and ADVISORY-ONLY.

It MUST NEVER

• Modify secrets
• Rotate credentials automatically
• Disable users
• Modify feature flags
• Modify configuration
• Restart services
• Place orders
• Modify portfolio
• Execute trades

Its responsibility is to monitor, validate, score and report security posture.
