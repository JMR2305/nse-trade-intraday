OBJECTIVE

Build a comprehensive Data Quality & Validation Framework for ApexQuant AI.

This module validates every piece of market, portfolio, paper-trading, AI, and analytics data before it is consumed by downstream modules.

This module MUST remain completely READ-ONLY and ADVISORY-ONLY.

It MUST NEVER

• Modify market data
• Modify paper trades
• Modify AI predictions
• Modify strategy outputs
• Modify portfolio
• Modify execution engine
• Auto-correct production data

Its responsibility is to detect, classify, score and report data quality issues.
