PHASE 22 — CONTROLLED AUTO PAPER TRADING AND EVIDENCE ACCUMULATION

Goal:
Safely activate automatic simulated paper-trade entries and exits so the platform can accumulate statistically useful evidence for Phase 21 calibration and champion–challenger evaluation.

This phase is PAPER / RESEARCH ONLY.

NON-NEGOTIABLE SAFETY RULES

- Never place, modify, or cancel a real Zerodha order.
- All live-order write routes must remain disabled.
- Broker connectivity may be used only for market data and account/session validation.
- Automatic paper entries must require explicit user confirmation.
- Kill switch, stale-data rules, risk limits, and audit logging must remain active.
- Phase 21 challengers remain advisory and cannot change champion decisions.

CURRENT STATE

- Production readiness: READY.
- Cross-page consistency: PASS.
- Hard mismatches: 0.
- Reproducibility: PASS.
- No-look-ahead: PASS.
- Ranking stability: DETERMINISTIC.
- Auto paper entries: OFF.
- Live orders: DISABLED.
- Phase 21 readiness: INSUFFICIENT_EVIDENCE.
- Historical completed trades are currently too few for reliable calibration.

PART 1 — PRE-ACTIVATION CHECKLIST

Create a mandatory Paper Automation Readiness checklist.

All checks must pass before automatic paper entries can be enabled:

- latest scan is FRESH
- canonical scan_id is consistent
- quote provider is approved
- no fallback data for the selected symbol
- market is open
- scheduler is healthy
- durable database is connected
- paper ledger is writable
- duplicate-position guard is active
- cash and risk limits are loaded
- daily loss limit is active
- kill switch is OFF
- auto paper exits are active
- live-order write paths are disabled
- audit logger is healthy
- no critical unresolved validation errors

If any check fails:
- block activation
- show the exact failed checks
- do not weaken any control

PART 2 — EXPLICIT USER ACTIVATION

Keep auto paper entries OFF by default after every deployment.

Add a confirmation dialog:

“I understand this enables automatic simulated paper trades only. No real Zerodha orders will be placed. Paper trades can gain or lose simulated capital.”

Require the user to type:

ENABLE PAPER ONLY

After confirmation:

- set auto paper entries ON
- record user, timestamp, configuration hash, and audit event
- show a persistent PAPER AUTOMATION ACTIVE banner
- provide an immediate Disable button

Do not reuse this confirmation for live trading.

PART 3 — ENTRY ELIGIBILITY

Create a paper entry only when all champion-model gates pass:

- recommendation is BUY or STRONG BUY
- fresh canonical scan
- symbol quote is current and available
- no fallback or stale source
- Phase 21 champion decision only
- eligible strategy for current regime
- minimum confidence passed
- minimum opportunity score passed
- minimum trade-quality score passed
- minimum risk/reward passed
- valid stop and target
- position size greater than zero
- sufficient simulated cash
- daily trade count available
- no open position for the same symbol
- cooldown passed
- per-stock cap passed
- sector cap passed
- deployed-cap passed
- risk-per-trade passed
- daily simulated loss limit passed
- kill switch inactive

Store every passed and failed gate.
