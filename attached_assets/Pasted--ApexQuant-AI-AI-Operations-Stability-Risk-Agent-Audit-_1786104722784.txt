# ApexQuant AI - AI Operations Stability & Risk Agent Audit (Version 4.3)

The AI Operations Centre has exposed several backend inconsistencies. This phase is NOT about adding new UI. It is about making the entire AI pipeline reliable, explainable, and internally consistent.

====================================================
PART 1 - RESEARCH AGENT FAILURE
====================================================

The Research Agent is currently entering ERROR state with messages such as:

- Snapshot collection timed out
- Worker timed out
- No refresh timestamp
- No news processed
- No sentiment
- No corporate actions

This is unacceptable for production.

Investigate and fix:

• API timeout handling
• Worker timeout configuration
• Queue deadlocks
• Missing retry logic
• Database lock/contention
• Thread starvation
• Network timeout
• Scheduler overlap

Implement automatic retry.

Retry 3 times using exponential backoff.

If Research still fails:

Supervisor must decide ONE of two modes.

Option A (Fail Open)

Continue pipeline using market-only analysis.

Mark every downstream decision:

"Research unavailable - Market-only mode"

Option B (Fail Closed)

Stop downstream pipeline.

Show clear reason.

Do NOT allow inconsistent partial execution.
