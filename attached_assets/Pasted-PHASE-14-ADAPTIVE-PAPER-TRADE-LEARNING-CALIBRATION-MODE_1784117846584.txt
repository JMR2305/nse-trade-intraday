PHASE 14 — ADAPTIVE PAPER-TRADE LEARNING, CALIBRATION & MODEL GOVERNANCE

Implement Phase 14 in the existing NSE Trader application.

OBJECTIVE

Build a safe adaptive-learning layer that learns only from completed historical and paper trades, improves future confidence and strategy ranking, and never changes live or paper-trading behaviour automatically without explicit human approval.

The system must remain:

- Paper trading and research first
- No automatic real-money execution
- No look-ahead leakage
- No self-modification of production rules
- Fully explainable
- Reversible and auditable
- Conservative when evidence is limited

Do not weaken any existing safety gates, broker controls, data-quality checks, market-hours checks, position limits, or Phase 13 logic.

- exit price

- sector-strength score at entry

- volume score

- liquidity score

- final recommendation at entry
- actual outcome: win, loss, breakeven
- whether stop or target was hit first
- data-quality status at entry
- model version
- feature version

Never use information that became available after the trade entry when constructing entry features.

Add an explicit no-look-ahead audit for every learning row.

- win rate

- performance by confidence band
- performance by opportunity-score band
- performance by strategy

Metrics must show sample size and reliability labels:

- MODERATE: 50–99
- STRONG: 100–249
- HIGH: 250+

Do not display strong conclusions from low-sample groups.

--------------------------------------------------
3. ADAPTIVE LEARNING ADJUSTMENTS
--------------------------------------------------

Create conservative evidence-based adjustments for:

- strategy
- strategy × regime
- strategy × sector
- confidence band
- opportunity-score band
- holding-period band
- trade-quality grade

Each adjustment must include:

- adjustment value
- sample size
- expectancy
- profit factor
- win rate
- reliability level
- last-updated timestamp
- evidence period
- reason
- upper and lower safety bounds

Rules:

- Maximum adjustment per evidence source: ±5 confidence points
- Maximum total adaptive adjustment: ±10 points
- Insufficient evidence must contribute 0
- Negative expectancy with moderate-or-better evidence may reduce confidence
- Positive expectancy must not increase confidence unless profit factor is above 1 and the sample size is sufficient
- Never allow adaptive learning to turn an IGNORE directly into BUY
- Never bypass risk filters
- Never override stale-data blocks
- Never override market-regime eligibility
- Never modify stop-loss, risk caps, or capital limits automatically

The learning layer should influence ranking conservatively, not manufacture trade signals.

--------------------------------------------------
4. CONFIDENCE CALIBRATION
--------------------------------------------------

Implement rolling confidence calibration using completed out-of-sample paper trades.

Support:

- isotonic regression when sufficient data exists
- Platt scaling as a fallback
- identity calibration when evidence is insufficient

Requirements:

- Fit only on trades completed before the current scan
- Version every calibrator
- Preserve historical calibrators
- Report raw versus calibrated confidence
- Show Brier score, ECE, and log loss before and after calibration
- Automatically fall back to the previous stable calibrator when a new calibrator performs worse out-of-sample
- Never fit and evaluate on the same observations

Display a warning when fewer than 100 completed trades are available.

--------------------------------------------------
5. CHAMPION–CHALLENGER MODEL GOVERNANCE
--------------------------------------------------

Add a model registry containing:

- model version
- status: DRAFT, CHALLENGER, CHAMPION, REJECTED, ARCHIVED
- creation timestamp
- feature version
- calibration version
- learning-data cutoff
- evaluation window
- number of OOS trades
- expectancy
- profit factor
- Sharpe
- drawdown
- Brier score
- ECE
- failure flags
- approval status
- approved by
- approval timestamp
- rollback target

A challenger must not replace the champion automatically.

Promotion requires:

- at least 100 completed out-of-sample trades
- at least 3 independent test windows
- positive net expectancy after all costs
- profit factor greater than 1.10
- Sharpe greater than 0
- acceptable drawdown
- no look-ahead violations
- calibration no worse than champion
- no safety-regression tests failing
- explicit human approval

Create one-click rollback to the previous champion for research and paper mode.

No model may be promoted to live-assisted mode automatically.

--------------------------------------------------

- INFO

- CRITICAL

Critical drift must:

- freeze positive learning adjustments
- retain risk-reducing adjustments
- prevent model promotion
- create a notification
- display a banner on AI Decision and Model Governance
- never disable existing safety controls

FINAL ACCEPTANCE CRITERIA

Phase 14 is complete only when:

1. Learning uses completed trades only.
2. Every learning row passes a no-look-ahead audit.
3. Small samples do not produce unsupported adjustments.
4. Confidence adjustments are capped and explainable.
5. Calibration is trained without leakage.
6. Challengers cannot self-promote.
7. Human approval is mandatory.
8. Drift can freeze learning safely.
9. Existing risk and execution controls remain unchanged.
10. All tests pass.
11. No real broker order is placed.
12. A complete diagnostic export is available for external review.

Implement this directly in the existing application. Preserve all existing pages and functionality. Do not replace working Phase 13 logic; extend it safely.
