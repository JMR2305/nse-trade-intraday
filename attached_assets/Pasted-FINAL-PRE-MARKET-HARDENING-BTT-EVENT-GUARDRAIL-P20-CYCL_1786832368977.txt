TASK 1 — QUARANTINE BACKTEST / BTT EXECUTION EVENTS

Problem:
backtest_portfolio.py can emit ORDER_EXECUTED events with BTT- trade IDs into the same pipeline_events table as real canonical P20 paper trades. This can pollute dashboards and make replay executions look like real paper executions.

Fix:
1. In backtest_portfolio.py and market_replay.py, do not emit canonical ORDER_EXECUTED for replay/backtest fills.
2. Rename replay execution events to:
   - REPLAY_ORDER_SUBMITTED
   - REPLAY_EXECUTION_COMPLETED
   - REPLAY_ORDER_REJECTED
   or similar namespaced event types.
3. Add payload field:
   source = "replay" or "backtest"
   canonical_trade = false
4. Keep canonical live/paper executor events as:
   ORDER_SUBMITTED
   ORDER_EXECUTED
   ORDER_REJECTED
   only for P20- trade IDs from phase20_executor.py.
