# ApexQuant AI - Replay Engine V4.2 (Data Integrity + Portfolio Flow)

The replay engine is working well visually, but there are still backend data consistency problems. This phase is NOT a UI redesign. It is a data integrity and replay engine enhancement.

====================================================
PART 1 - FIX PIPELINE COUNT CONSISTENCY
====================================================

The replay must behave like a real processing pipeline.

For EVERY stage enforce:

Input = Passed + Rejected + Cancelled + Pending

No stage may create or destroy records.

Current incorrect example:

Decision
48 -> 6

Execution
6 -> 7

Rejected = -1

This is mathematically impossible.

Negative rejected counts must never exist.

Execution cannot output more symbols than it received.

The replay validator should automatically detect and highlight any inconsistency.

====================================================
PART 2 - SINGLE SOURCE OF TRUTH
====================================================

Every replay page must use the same replay dataset.

Do NOT calculate counts separately.

Every stage must read from the same ReplaySession object.

Example:

ReplaySession

Market Scanner

Research

Market Intelligence

Monitoring

Strategy

Risk

Decision

Execution

Portfolio

The UI should simply display ReplaySession values.
