--------------------------------------------------
3. DEPENDENCY ISOLATION
--------------------------------------------------

Resolve dependency conflicts without breaking the existing workspace.

Known issues:

- V0 React: 19.2.4
- Workspace React: 19.1.0
- V0 lucide-react: ^1.16.0
- Workspace lucide-react: ^0.545.0
- V0 Next.js: 16.2.6
- V0 @vercel/analytics dependency

Preferred approach:

1. Keep the Document Hub dependency resolution isolated as much as pnpm workspace rules allow.
2. Do not upgrade the entire monorepo to React 19.2.4.
3. Do not change Expo or mobile dependencies.
4. First test whether the V0 project works safely with React 19.1.0.
5. Keep lucide-react isolated to the Document Hub package.
6. Remove @vercel/analytics only if required for non-Vercel runtime compatibility.
7. Preserve functional UI behaviour.

Document every package version changed.
