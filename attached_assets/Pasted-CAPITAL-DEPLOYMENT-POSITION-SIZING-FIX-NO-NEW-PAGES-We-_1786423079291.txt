====================================================
TASK 2 — ADD CONTROLLED SCALE-IN LOGIC
====================================================

Current behaviour:
If one position is open, all future approved BUYs for the same symbol are cancelled.

New behaviour, only when scale_in_enabled = true:

Allow an additional BUY tranche only if:

1. Existing position is profitable or not deeply negative.
2. Fresh BUY-class signal exists.
3. Confidence passes threshold.
4. Risk/reward passes threshold.
5. Total symbol exposure remains within max_symbol_exposure_pct.
6. Total portfolio exposure remains within max_total_exposure_pct.
7. Scale-in count is below max_scale_in_count.
8. Stop-loss and target are valid.
9. Cash is sufficient.
10. No market safety gate fails.

Every scale-in must create clear events:

- SCALE_IN_APPROVED
- SCALE_IN_REJECTED
- SCALE_IN_EXECUTED

Store exact reason if rejected.

Do not silently merge or hide scale-in trades.

====================================================
TASK 3 — PRESERVE ONE-POSITION RULE WHEN SCALE-IN OFF
====================================================

If scale_in_enabled = false, current behaviour must remain unchanged.

Open position should still block duplicate symbol entries.

Add regression test proving current behaviour is preserved by default.

====================================================
TASK 4 — TIME-NORMALIZE INTRADAY VOLUME GATE
====================================================

The audit found morning volume is compared against full-day average volume, causing the volume ratio to be structurally low early in the session.

For intraday mode only:

Replace raw:
session_so_far_volume / average_full_day_volume

with:
session_so_far_volume / average_session_to_date_volume_at_same_time

Example:
09:45 volume should be compared against average 09:45 accumulated volume, not full-day volume.

Important:
- Apply only to intraday scans/backtests.
- Daily mode remains unchanged.
- If time-of-day volume curve is unavailable, fall back safely and label evidence as insufficient.
- Do not fabricate volume curve data.
