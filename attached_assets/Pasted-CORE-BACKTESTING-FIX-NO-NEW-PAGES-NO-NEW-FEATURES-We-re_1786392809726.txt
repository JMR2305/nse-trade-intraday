TASK 4 — FIX VALIDATION V2 SILENT BACKGROUND FAILURES
===============================================================================

Audit found a real blocker:

Validation V2 background executor can fail silently because stdio is ignored.
A crash can leave a run stuck RUNNING forever.

Fix:

1. Capture stderr/stdout from the background executor.
2. If the run crashes:
   - set status=FAILED
   - store error text on the run row
   - show error in /validation-v2 UI
3. Add stuck-run timeout:
   - if RUNNING too long without progress, mark as FAILED or STALE
   - show remediation message
4. Add tests:
   - background crash marks run FAILED
   - error text is persisted
   - UI shows failed run instead of endless running
