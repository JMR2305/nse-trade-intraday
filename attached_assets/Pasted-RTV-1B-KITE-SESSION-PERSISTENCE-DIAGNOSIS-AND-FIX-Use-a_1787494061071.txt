TASK 4 — CHECK NODE/PYTHON TOKEN VISIBILITY

Verify:

Node API
→ token store

A. only in Node memory

TASK 5 — CHECK AUTOSCALE / INSTANCE PERSISTENCE

RTV-0 noted a public Autoscale deployment.

Determine whether authentication is being saved to instance-local ephemeral storage.

Verify:

- number of runtime instances
- whether callback request and later status request can hit different instances
- whether token persistence is instance-local
- whether filesystem storage is durable across Autoscale instances
- whether development and deployed filesystems differ

If token storage is local/ephemeral, classify as:

ROOT CAUSE — NON-DURABLE / INSTANCE-LOCAL SESSION STORAGE

The access token must be available to every runtime process that needs read-only Kite data.
