🧠 AI Operations Centre

This page will become the real-time operational dashboard for the complete ApexQuant AI Multi-Agent system.

The goal is to make the AI completely transparent.

At any moment the operator should know:

• Which agent is currently running
• When each agent last refreshed
• What data each agent received
• What data each agent forwarded
• Why any stock was rejected
• Whether the agent is healthy
• Whether the pipeline is progressing normally

This page is READ ONLY.

No manual intervention.

No trading controls.

Display operational information only.
