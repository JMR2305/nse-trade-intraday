Build Sprint 3 - Module 3: Adaptive Learning Layer.

Objective:
Use the Historical Knowledge Base (3,355+ simulated trades) to improve Market Scanner decisions.

Important:
- Do NOT change any existing strategy logic.
- Do NOT change entry or exit rules.
- Learning must only adjust confidence and ranking.
- Every adjustment must be explainable.
- Never use black-box AI or ML.

--------------------------------------------------
1. Similar Pattern Search
--------------------------------------------------

For every new scanner signal:

Search the historical database for similar trades based on:

- Strategy
- Sector
- Market Regime
- RSI band
- ADX band
- EMA alignment
- Volume ratio band
- Risk/Reward band
- Holding period

Return:

- Similar Trades
- Wins
- Losses
- Win Rate
- Average Return
- Profit Factor
- Expectancy

--------------------------------------------------
2. Confidence Adjustment
--------------------------------------------------

Current scanner produces:

Base Confidence

Historical Learning then adjusts it.

Rules:

If

Trades >= 30
AND
Win Rate > 60%
AND
Profit Factor > 1.5

Increase confidence:

+5 to +15

--------------------------------

If

Trades >= 30
AND
Win Rate < 45%
AND
Profit Factor < 1

Reduce confidence:

-5 to -20

--------------------------------

If

Trades < 30

Adjustment:

0

Show:

Low historical confidence

--------------------------------

Never exceed

95

Never go below

5

--------------------------------------------------
