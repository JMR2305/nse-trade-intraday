# PHASE 15 – PRODUCTION HARDENING & STABILIZATION

## OBJECTIVE

We have completed the majority of the NSE Trader research platform. This phase is NOT about adding new features or pages. The objective is to transform the existing platform into a stable, production-quality research application that is internally consistent, reliable, explainable, and ready for extended paper trading.

Treat this as a production hardening sprint.

======================================================================

## 1. UNIFIED SCAN ENGINE (HIGHEST PRIORITY)

Create a centralized Scan Context shared across the entire application.

Every module must consume the exact same scan snapshot.

Modules include:

- Dashboard
- Market Scanner
- AI Decision
- AI Copilot
- Portfolio Manager
- Portfolio Risk Analytics
- Performance Analytics
- Notifications
- Learning & Governance
- Trade Replay
- Watchlist

Every page must use identical values for:

• Scan ID
• Scan Timestamp
• Market Regime
• Confidence
• Opportunity Score
• Technical Indicators
• Sector Rankings
• Risk Metrics
• Position Sizing
• Strategy Recommendation

There must be only ONE source of truth.

Refreshing one scan should automatically synchronize every page.

======================================================================

## 2. CROSS-PAGE CONSISTENCY VALIDATION

Implement automatic validation across the application.

Example:

If Market Scanner shows

INDUSINDBK
Score = 43.9

then AI Decision, AI Copilot, Notifications, Portfolio and Performance Analytics must all display exactly the same value.

If any inconsistency exists:

• Log the error
• Highlight it in Diagnostics
• Prevent conflicting recommendations

======================================================================

## 3. DATA QUALITY ENGINE

Introduce a Data Quality Score for every stock.

Calculate using:

• Price Feed
• Volume Data
• Indicator Completeness
• Historical Data
• Corporate Actions
• Missing Candle Detection

Generate:

95-100 = Excellent

90-94 = Good

80-89 = Warning

Below 80 = Do Not Trade

Display this score alongside every recommendation.

======================================================================

## 4. STALE DATA DETECTION

Track:

Current Time

Show elapsed time

Disable BUY recommendations
