GOAL:
Fix the confirmed Phase 0B safety failures before any Phase 1 architecture work.

Confirmed failures:
1. `_manage_paper()` ran exits first and then entries in the same tick, allowing a new entry after square-off.
2. The deployed admission path allowed AUTO / BOOTSTRAP_AUTO entries after the 15:15 IST cutoff.

5. Cold-start force close worked, but only as backup and with fill-price fallback.

- `manage_open_positions()` may still run after 15:15.
- But `run_auto_entries()` and `run_bootstrap_auto_entry()` must not run if `automatic_paper_entry_status().allowed` is false.
- This must block both AUTO and BOOTSTRAP_AUTO.
- Return explicit output:
  - entries skipped reason: `ENTRY_WINDOW_CLOSED`

  - cutoff time
  - checked_at_ist
  - market_state
