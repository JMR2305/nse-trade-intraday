# Create "Phase Review Package"

After every completed phase, generate a downloadable review package for ChatGPT.

The objective is to allow a complete technical review without requiring dozens of screenshots.

Create a ZIP file named:

Phase10_Review_Package.zip

(or automatically use the current phase number.)

The ZIP should contain the following:

==================================================
1. implementation_summary.md
==================================================

Include:

- Phase number
- Date
- Features implemented
- Files modified
- Files created
- Database migrations
- API endpoints added
- Tests added
- Tests passed
- Known limitations
- TODO items
- Bugs
- Performance notes

EXPORT
==================================================

Add a new button in Settings:

Generate the ZIP.

Display:

Total size

Any warnings

==================================================
QUALITY REQUIREMENTS
==================================================

Do not generate placeholder screenshots.

Only include existing pages.

Mark unavailable sections honestly.

Do not fabricate metrics.

If data is unavailable, clearly state:

"Not Available"

rather than inventing values.

The package must be complete enough that ChatGPT can review the entire phase from the ZIP contents without requiring additional screenshots.
