OBJECTIVE

Build the foundational Multi-Agent Framework for ApexQuant AI.

This phase establishes the infrastructure required for all future intelligent agents.

It introduces:

• Agent Framework
• Agent Registry
• Supervisor Agent
• Shared Snapshot Bus
• Market Data Agent
• Research Agent

This phase MUST NOT modify

• Trading Engine

• Risk Engine

• Portfolio Engine

• Strategy Logic

• AI Models

• Order Execution

All agents operate in READ-ONLY and ADVISORY-ONLY mode.

SHARED SNAPSHOT BUS

Implement a shared snapshot system.

Agents publish snapshots.

Agents subscribe to snapshots.

No direct agent-to-agent calls.

Example

Market Data Agent

publishes

Market Snapshot

Research Agent

publishes

Research Snapshot

Future agents consume snapshots.
