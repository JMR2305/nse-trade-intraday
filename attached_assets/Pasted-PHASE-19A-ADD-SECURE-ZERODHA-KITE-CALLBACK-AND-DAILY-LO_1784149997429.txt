   - Reject missing, invalid, or failed login responses.

     api_key + request_token + api_secret

   - Store the resulting access token securely on the backend.
   - Record token creation time and connection status.
   - Redirect the user back to:
     /trading-dashboard/kite-connect?auth=success
     or
     /trading-dashboard/kite-connect?auth=failed
