ApexQuant AI – Phase 5D Enhancement
Replace Yahoo Finance with a Multi-Provider Pre-Open Data Layer

Background

The current Pre-Open Intelligence module works correctly, but its functionality is limited because it primarily relies on Yahoo Finance (yfinance).

Yahoo Finance does not expose the complete NSE pre-open auction book, which results in missing information such as:

- Buy Quantity
- Sell Quantity
- Buy/Sell Imbalance
- Indicative Equilibrium Price (IEP)
- Matched Quantity
- Complete auction statistics

The goal is NOT to change the UI.

The goal is to improve the data source.

--------------------------------------------------

OBJECTIVE

Implement a multi-provider pre-open data architecture.

Priority:

1. NSE official pre-open data (Primary)
2. Zerodha Kite APIs (Secondary)
3. Yahoo Finance (Fallback only)

--------------------------------------------------

NEW DATA SOURCE PRIORITY

Primary Provider

NSE Official Pre-Open Market Data

Fetch whenever available.

Use it to populate:

• Indicative Price
• Previous Close
• Gap %
• Buy Quantity
• Sell Quantity
• Buy/Sell Imbalance
• Indicative Matched Quantity
• Total Traded Quantity
• Auction Statistics

--------------------------------------------------

Secondary Provider

Zerodha Kite APIs

Evaluate whether Kite provides any additional useful information for:

• Quotes
• Market depth
• Instrument metadata
• Trading session validation

Use Zerodha wherever it improves reliability.

--------------------------------------------------

Fallback Provider

Yahoo Finance

Use ONLY if:

- NSE data is unavailable
- Zerodha data is unavailable

Yahoo should never be the preferred provider for pre-open auction analytics.
