We need to stop fixing pages individually and instead perform a COMPLETE DATA ARCHITECTURE CONSOLIDATION.

The current issue is that multiple pages appear to calculate their own values independently instead of reading from one canonical source.

Examples observed:

• Replay shows different counts than AI Operations Centre.
• Portfolio shows zero trades while execution shows BUYs.
• Trade History is empty.
• Portfolio Performance is empty.
• Validation shows different statistics.
• Phase 4A shows another set of values.
• Broker page imports fail.
• Some pages still use cached/demo/generated data.

This entire architecture must be unified.
