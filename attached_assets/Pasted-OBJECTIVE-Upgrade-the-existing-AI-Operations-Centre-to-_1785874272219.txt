OBJECTIVE

Upgrade the existing AI Operations Centre to Version 2.

The purpose of Version 2 is to eliminate guesswork.

At any moment the operator should immediately know:

• Which agent is working
• Which agent is waiting
• Which agent is delayed
• Which agent is blocking the pipeline
• Why stocks did not flow to the next agent
• Whether the data is stale
• Whether intervention is required

Keep the existing Version 1 page.

Enhance it.

DO NOT redesign the layout.
